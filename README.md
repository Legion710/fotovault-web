# Fotovault — marketing site

The public marketing site for **Fotovault**, served at
[fotovault.co.za](https://fotovault.co.za) via GitHub Pages.

Static HTML only (self-contained: inline CSS, no build step). Sign-in and
sign-up links point to the app at **portal.fotovault.co.za** (a separate,
private repository).

- `index.html` — landing page
- `terms.html` — Terms & Conditions
- `privacy.html` — POPIA Privacy Policy
- `CNAME` — custom domain for GitHub Pages
